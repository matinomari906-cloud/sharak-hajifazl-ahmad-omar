# شهرک رهایشی حاجی فضل احمد عمر

این مخزن شامل نسخه اولیه و آماده برای هاستینگ وب‌سایت شهرک رهایشی حاجی فضل احمد عمر است.

## ساختار فایل‌ها

- `index.html` — صفحه اصلی
- `404.html` — صفحه خطای 404
- `styles.css` — استایل‌های سایت
- `script.js` — اسکریپت‌های تعاملی
- `robots.txt` — برای سئو و ربات‌ها
- `sitemap.xml` — نقشه سایت
- `site.webmanifest` — فایل PWA
- `images/` — تصاویر گرافیکی پروژه

## راه‌اندازی روی هاست

1. فایل‌های این مخزن را در ریشه هاست یا پوشه public_html آپلود کنید.
2. اگر هاست Apache است، فایل `.htaccess` را اضافه کنید تا صفحه 404 درست نمایش داده شود.
3. دامنه خود را به هاست متصل کنید.
4. وب‌سایت در آدرس اصلی دامنه شما قابل دسترسی خواهد بود.

## فایل 404

برای فعال‌سازی صفحه 404 در Apache، این خط را به `.htaccess` اضافه کنید:

```apache
ErrorDocument 404 /404.html
```

## نکته

دامنه `example.com` در فایل `robots.txt` و `sitemap.xml` به‌صورت نمونه است و باید با دامنه واقعی شما جایگزین شود.
