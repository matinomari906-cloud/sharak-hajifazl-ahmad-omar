# Matin Pocket برای ویندوز

این پوشه یک فضای شخصی برای وظایف، یادداشت‌ها، ایده‌ها، اسناد، مدیریت ابزارآلات و ثبت‌های مالی است. در بخش ابزارآلات می‌توانید نام، دسته‌بندی، تعداد، توضیحات و وضعیت هر وسیله را ثبت کنید. برنامه از فایل‌های محلی اجرا می‌شود و برای کارکرد اصلی به اینترنت نیاز ندارد.

## نصب میان‌بر

1. پوشهٔ `matin-pocket` را در محل دلخواه و دائمی نگه دارید.
2. روی `Install-MatinPocket.ps1` راست‌کلیک کنید و **Run with PowerShell** را بزنید.
3. میان‌بر **Matin Pocket** روی دسکتاپ ساخته می‌شود. برای بازکردن برنامه دوبار روی آن کلیک کنید.

اگر اجرای اسکریپت از منوی راست‌کلیک در دسترس نبود، PowerShell را در همین پوشه باز کنید و اجرا کنید:

```powershell
.\Install-MatinPocket.ps1
```

برای استفاده بدون ساخت میان‌بر، `Start-MatinPocket.bat` را اجرا کنید. برنامه در پنجرهٔ مستقل Microsoft Edge باز می‌شود؛ نصب Microsoft Edge لازم است.

## نگهداری اطلاعات

اطلاعات در فضای ذخیره‌سازی محلی Edge روی همین ویندوز می‌ماند و به فضای ابری فرستاده نمی‌شود. در بخش **تنظیمات و پشتیبان** می‌توانید نسخهٔ پشتیبان JSON بگیرید یا اطلاعات را بازیابی کنید. پشتیبان‌ها را در محل امن نگه دارید؛ پاک‌کردن داده‌های مرورگر می‌تواند اطلاعات برنامه را حذف کند.
